# Mobile Zoom Fix — ImageLightbox

**Дата:** 2026-08-04
**Компонент:** `frontend/src/components/ImageLightbox`

---

## Проблема

### 1. Двойной тап не сбрасывает зум на мобильных

В `handleTouchEnd` при `isZoomed === true` выполняется ранний return (строка 333–337), который сохраняет позицию для панорамирования и **не проверяет двойной тап**. Код двойного тапа (строки 340–349) недостижим, когда изображение уже увеличено.

### 2. Пинч-зум работает рывками

CSS-транзиция `transition: transform 0.15s ease-out` на элементе `.image` активна постоянно. При пинче каждый новый `scale` анимируется 150 мс, а пальцы движутся быстрее — масштаб «догоняет» рывками.

Дополнительно: `touch-action: pan-y` на overlay может конфликтовать с пинч-жестом на некоторых браузерах и браузерных движках.

---

## Дизайн решения

### Часть A — Исправление тапов (мобильные)

**Файл:** `ImageLightbox.tsx`

**Изменение в `handleTouchEnd`:**

1. Убираем ранний return при `isZoomed`
2. Добавляем логику «короткого тапа»:
   - Вычисляем расстояние между `touchstart` и `touchend` (по `touchStartX/Y` и последней позиции курсора)
   - Если расстояние < `DRAG_THRESHOLD` и `isZoomed` → `resetZoomState()` (сброс одним тапом)
   - Если расстояние < `DRAG_THRESHOLD` и не `isZoomed` → существующая логика двойного тапа (zoom in)
   - Если расстояние >= `DRAG_THRESHOLD` — это был свайп/пан, ничего не делаем

3. **Свайп вниз при зуме — закрытие:**
   - Если `isZoomed` и пользователь сделал свайп вниз (deltaY > 80px) → `onClose()`
   - Если `isZoomed` и свайп вбок/вверх — существующее панорамирование

**Изменение в `handleTouchStart` (1 палец):**
- Сохраняем `touchStartX.current` и `touchStartY.current` всегда (не только когда `!isZoomed`)

**Блок-схема `handleTouchEnd` после изменений:**

```
handleTouchEnd
├─ isPinching → isPinching = false, return
├─ isZoomed
│  ├─ была дистанция (свайп)
│  │  ├─ deltaY > 80 → onClose()
│  │  └─ иначе → dragPos = position (пан)
│  └─ короткий тап → resetZoomState()
└─ !isZoomed
   ├─ короткий тап
   │  ├─ двойной → zoom in
   │  └─ одиночный → запомнить время
   └─ свайп вбок → goPrev / goNext
```

### Часть B — Плавный пинч

**Файлы:** `ImageLightbox.tsx`, `ImageLightbox.module.css`

1. **Временное отключение transition:**
   - В `handleTouchMove` при начале пинча: устанавливаем `imageRef.current.style.transition = 'none'`
   - В `handleTouchEnd` при завершении пинча: `imageRef.current.style.transition = ''` (возврат к CSS-значению)

2. **`touch-action` на overlay:**
   - Меняем `touch-action: pan-y` на `touch-action: none` — лайтбокс и так с `overflow: hidden`, браузерный скролл не нужен

### Часть C — Десктоп (без изменений)

Существующее поведение на десктопе не меняется:
- Колесо мыши — зум
- Двойной клик — зум в точке / сброс
- Одиночный клик при зуме — сброс
- Drag для панорамирования

## Критерии успеха

1. **Двойной тап** на мобильном: приближает, повторный двойной тап — не нужен, один тап сбрасывает
2. **Один тап** на мобильном при зуме: сбрасывает масштаб
3. **Пинч** на мобильном: масштабируется плавно, без рывков
4. **Свайп вниз** при зуме: закрывает лайтбокс
5. **Свайп вбок** без зума: перелистывает фото
6. **Десктоп**: всё работает как раньше
7. **Transition**: возвращается на изображение после завершения пинча
